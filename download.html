Three steps

No build step, no package manager, no environment file.

1

Unzip it anywhere

Pick any folder. It does not care where it lives and it writes nothing outside it.

unzip Campus-Nexus-1.0.0.zip
# Windows: right-click → Extract All
2

Check Node is there

It needs 22.5 or newer. Anything older has no node:sqlite, which is the only reason for the floor.

node --version
# v22.5.0 or above
3

Start it

Windows users can double-click start.bat. It prints the address and opens the browser.

node server.js
# or: start.bat  on Windows

i Sign in

  • admin / admin123 — full access
  • staff / staff123 — counter only
  • Change both before putting this anywhere other than your own machine.

✓ What the first run makes

  • 20 books, 25 products and a bill history, seeded
  • data/campus-nexus.db from src/schema.sql
  • A fresh HMAC pepper and data key in SECURITY/
  • An audit chain of 120 sealed blocks

! Before you expose it

  • Demo logins are printed on every start
  • Sessions are in memory — a restart signs everyone out
  • It binds localhost by default, which is deliberate
  • SECURITY.md lists what it does not cover

Also worth knowing

Prefer a hosted instance?

  • The repository ships a render.yaml and a Procfile
  • Any Node host works — it just runs node server.js
  • Needs a writable disk for the SQLite file and the key folder

Check it before you trust it

  • npm test — 45 end-to-end checks over HTTP
  • npm run test:security — 98 attack checks
  • npm run test:pii — greps the database for plaintext
  • All 165 pass against the release you just downloaded

What is not in the archive

  • The website files — they are online and unused at runtime
  • 2.3 MB of screenshots, for the same reason
  • Any key, database or build residue, by design
  • Your data, obviously — it is created fresh per machine
